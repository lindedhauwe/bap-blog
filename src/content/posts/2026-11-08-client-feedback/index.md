## Feedback from the client

A week ago, we sent our first concept proposal to the client as a pitch deck, together with a form to evaluate it. Today we received our results and some extra feedback.

We had to wait a week for this feedback, because the client was busy hosting Boektopia. That caused a small delay in our project, since we couldn't really move forward without it.

## Results

We scored **15/20**. The client rated each criterion on a scale from -- (strongly disagree) to ++ (strongly agree).

| Category | Criterion | Rating |
| --- | --- | --- |
| Concept | Preliminary research | ++ |
| | Fits the briefing | + |
| | Original | +- |
| | Feasible | + |
| Target group | Clearly defined target group | + |
| | Convinces the client and the target group | +- |
| | Choices to test are named | + |
| Communication & presentation | Enthusiasm | ++ |
| | Structure & story | ++ |
| | Slides are self-explanatory | ++ |
| | Polished design | ++ |
| Collaboration | Constructive collaboration | + |
| | Disciplines used | +- |
| | Decisions made together | +- |

Our research and the way we presented it scored best. The points to work on are originality, convincing the client and the target group, using all our disciplines, and making decisions together.

The client also added this feedback:

> "I think the research is spot on, these are exactly the kind of people we want to get interested in books. What isn't entirely clear to me is how the games link back to books. Video games that are vaguely related to books by means of genre is not enough of a link for me."

## Next steps

We'll continue with our concept and take this feedback into account. In the meantime, we're working out the mini-games further. We keep in mind that the client might ask us to go smaller, so we make sure the concept can be scaled down if needed.

We're also planning a meeting with the client on Thursday morning 12 November, where we'll ask some questions that aren't fully clear to us yet, such as:

- Do you agree with the size of our installation?
- Which discipline(s) did we not use?
